# v0.4.0 (seeing) manual QA: FD-21 keyboard walkthrough and human review loop

This is the manual QA checklist for the v0.4.0 (seeing) release gate
(`docs/internal/releases/v0.4.0-seeing/spec.md`, Release Gate section,
G-1/G-4), and closes test-strategy.md Section 6's "E2E GUI automation:
deliberately deferred" skeleton for this release: the review loop, first-run
and root selection, error-states sampling, the FD-21 keyboard walkthrough, and
both themes. The component-level a11y gate (axe-core smoke, token-contrast
script) is automated (T-36/T-35, `pnpm test`); this checklist is the human
half jp performs on the real Windows WebView2 build (architecture.md,
WebView2-only observability).

## Walkthrough

1. **First-run and library-root selection** (FD-05, AC-28/AC-29/AC-30).
   - Launch the app with no persisted library root (a fresh settings row,
     or `%APPDATA%\com.prisantlabs.audiobookorganizer` cleared).
   - Confirm the only path forward is "Choose your library folder", which
     opens the OS folder picker (`tauri-plugin-dialog`).
   - Pick a folder; confirm the app advances to the shell with that root
     persisted, default ruleset `abs-author-first` (D-02), default theme Day
     (FD-09).

2. **The review loop** (S-1 release plan v0.4.0 gate; AC-6..AC-20).
   - Open library home (F-902, "your library", never "dashboard").
   - Read the health facts (lede sentence, "worth a look first" shelf,
     series spines, good-news line) - confirm every number reads from the
     real scan, not a literal (AC-7).
   - Scan (or re-scan); confirm a real Stop control appears during the scan
     and cooperatively cancels at a safe boundary (AC-36), never mid-file.
   - Go to Tidy-up (review). Inspect a plan: seven group cards, include/skip
     switches, the footer's live "N of 7 groups - M changes" count.
   - Drill into a group's detail (right pane); open "Show file details" on an
     example and confirm raw paths, matched pattern, and confidence appear
     only inside that disclosure (FD-13).
   - Exclude one operation (AC-13); confirm it drops to excluded and the
     footer count updates.
   - Try the simple filter box (AC-16/AC-17): confirm it only changes what is
     shown, never approval state.
   - Attempt "Tidy up now": confirm the two-step inline confirm strip (never
     a modal) and the honest "not available in this version yet" copy (apply
     is v0.5.0).
   - "Save report" (if wired this release) or confirm the export affordance
     is present.

3. **Error-states sampling** (FD-04, F-908). Trigger and eyeball a
   representative subset:
   - Point the library root at a folder that does not exist (or rename it
     after first-run) and confirm the re-pick surface (AC-31).
   - Point the library root at an empty folder and confirm the "This folder
     doesn't have any audiobooks yet" empty state.
   - Toggle every group off in review and confirm "Tidy up now" is disabled
     with the explanatory line (AC-15, all-groups-excluded).
   - If feasible, exercise a permission-denied path (a Controlled Folder
     Access-protected test folder) and confirm the family-safe surface, not a
     raw OS error.

4. **Keyboard walkthrough** (FD-21 keyboard item, AC-41; design-system
   Section 7). Using only the keyboard (Tab / Shift+Tab / Enter / Space, no
   mouse):
   - Reach the theme segmented control; confirm `aria-pressed` state is
     announced and Tab order is sane through the titlebar.
   - Tab into the sidebar; confirm `aria-current="page"` on the active item
     and that every nav item is reachable.
   - On the review screen, Tab to a group card; confirm a visible
     `:focus-visible` ring (2px `--primary`, 2px offset), and that Enter
     selects the card and updates the detail pane (T-36 correction: the card
     is `role="button"`/`aria-pressed`, the include/skip switch is a
     separate, independently-Tab-reachable `role="switch"` control right
     next to it - confirm both are reachable and operable without a mouse).
   - Confirm the two-step "Tidy up now" confirm strip is fully keyboard
     operable (Enter/Space on "Go ahead" and "Not yet").
   - Confirm `prefers-reduced-motion` (OS setting) collapses the theme-swap
     and progress-bar transitions to near-instant (AC-4).

5. **Both themes** (Day and Evening, FD-09). Toggle the segmented control;
   confirm the whole shell (titlebar, sidebar, cards, chips, disclosures)
   re-themes with no unstyled flash and no `calm`/`prose` identifiers leak
   into markup or dev tools.
