# v0.1.0 (spine) manual QA: tracer slice, G-2

This is the manual QA checklist for gate G-2 (see
`docs/internal/releases/v0.1.0-spine/spec.md`, Release Gate section): "`pnpm
tauri dev` launches on Windows and the tracer slice works end to end
(AC-19)." It also closes the P4 logging cannot-verify (structured logging,
F-1003) by confirming a real scan writes log lines end to end.

## Walkthrough

1. Prepare a small fixture folder with mixed file types (an example layout
   that was actually used for the agent evidence below):

   ```text
   E:\tmp\abo-tracer\
     cover.jpg
     notes.txt
     track01.mp3
     sub1\book.epub
     sub1\list.m3u
     sub2\clip.mp4
     sub2\release.nfo
   ```

   (1 root dir + 2 subdirs + 7 files = 10 entries expected, since the scan
   records the root itself as the depth-0 entry.)

2. Launch the app: `pnpm tauri dev` from the repo root.
3. Wait for the window titled "Audiobook Organizer (v0.1.0 spine, throwaway
   UI)" to appear. Expect to see:
   - The heading "Audiobook Organizer - spine scaffold".
   - The note "Tracer slice - disposable, deleted at v0.4.0 (seeing)".
   - A small `db_status()` line (expect `{"recovered":false,"backup_path":null}`
     on a healthy DB).
   - A "Run tracer scan" button.
4. Click "Run tracer scan".
5. Expect, within a few seconds: a "Scan N complete (job N), 10 entries."
   line, followed by a `<pre>` block containing pretty-printed JSON: an
   array of entry objects (`id`, `scan_id`, `parent_id`, `path`, `name`,
   `kind`, `file_class`, `size`, `mtime`, `depth`).
   - `track01.mp3` must show `"file_class": "audio"`.
   - `cover.jpg` must show `"file_class": "image"`.
   - `clip.mp4` must show `"file_class": "video"`.
   - Total entry count must equal the fixture's file + dir count including
     the root (10 for the layout above).
   - If the scan fails instead, expect red text: "Scan failed (job N): ...".
6. Open the newest `abo.log` (path found on this machine at
   `%LOCALAPPDATA%\com.prisantlabs.audiobookorganizer\logs\abo.log`; the
   exact directory follows `tauri-plugin-log`'s `LogDir` resolution and may
   differ per machine/build identifier) and confirm it has a matching pair
   of lines:
   ```
   [...][abo_core::scan::persist][INFO] scan: started root=<fixture path>
   [...][abo_core::scan::persist][INFO] scan: completed scan_id=<N> entry_count=10 ...
   ```
7. Close the app / stop `pnpm tauri dev`.
