# v0.6.0 (hardening) manual QA: the human half of the release gate

The automated half of `FD-21` (accessibility verified, not promised) runs in
`pnpm test`: the axe-core smoke over each surface and the token-contrast script
over both themes. This file is the half a person performs on a real Windows
WebView2 build, following the convention set by
[`v0.4.0-manual-qa.md`](./v0.4.0-manual-qa.md) and
[`v0.1.0-manual-qa.md`](./v0.1.0-manual-qa.md).

## Walkthrough

1. **Interrupted tidy-up, keyboard only** (`AC-6` in v0.6.0 hardening, the
   resume-or-rollback offer; `FD-21` keyboard walkthrough).

   - Start a practice tidy-up, then kill the app process while it is running
     (Task Manager, End task). Reopen the app.
   - Confirm the recovery notice appears in the screen area, with the sidebar
     still visible and still navigable. A notice that traps you is a defect:
     the soft panel is deliberate, recorded in
     [`design-p1c-interruption-surface.md`](../releases/v0.6.0-hardening/design-p1c-interruption-surface.md).
   - Reach every control with Tab alone: the action button, the "Show details"
     disclosure, and the sidebar items. Confirm focus is visible on each, that
     Enter and Space both operate the button, and that Enter opens and closes
     the disclosure.
   - Confirm the wording is about a **practice run** and says nothing on your
     shelves was touched. If it offers to carry on, or offers to put changes
     back, that is a defect: a rehearsal has neither, because its effects lived
     in memory that died with the process.
   - Open "Show details" and confirm it holds plain facts only. Any raw path,
     job id, or operation id there is a defect (`AC-6`, `FD-13`).
   - Repeat the whole item in both Day and Evening themes.

   Note the states you cannot reach yet. The two real-tidy-up states (stopped
   with a verified outcome, and stopped with an unconfirmed one) need a real
   apply, which stays unreachable until the four preconditions in `STATUS.md`
   close. They ship covered by tests only, which is deliberate.

2. **Cancel mid-tidy-up** (`AC-8` in v0.6.0 hardening, the cancel walkthrough).
   Still open; owned by jp.

   - Cancel a run in the app.
   - Confirm it stops **between** changes and never mid-file-move.
   - Confirm what it leaves behind can be picked up again.

   The automated half already passes; this is the by-hand half, and it is the
   last open gate on `F-606` (interruption safety) once item 1 is walked.
