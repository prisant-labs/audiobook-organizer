# v0.2.0 baseline delta (2026-07-04)

The first fresh, strictly READ-ONLY look at the operator's real 297 GB library
since the 2026-03-25 WizTree baseline (FD-18). Every figure in the "2026-03-25
(FD-18)" column is a **2026-03-25 baseline, pending fresh scan** number; the
"LIVE 2026-07-04" column is that fresh scan. Per OQ-2 the drift is REPORTED, not
judged: the library has changed since March, so a delta is expected and is
itself the deliverable. G-03 does not fail on drift alone.

## How these numbers were produced (read-only method)

Generated by the ignored integration test `tests/real_library_scan.rs`:

```text
cargo test -p abo-core --test real_library_scan -- --ignored --nocapture
```

It runs the shipped, hardened P1-P6 engine three ways and compares:

1. **Live scan** of `E:\Books - Audio` through `scan::run_scan` (a `walkdir`
   walk plus `stat`; it writes nothing to the library, only to a throwaway
   temp-dir SQLite database).
2. **WizTree CSV import** of `_local/prior-work/WizTree_2026-03-25.csv` through
   `scan::run_csv_import` (G-07), classified and measured through the identical
   downstream path (F-102's "indistinguishable downstream" contract).
3. **FD-18 baselines**, hardcoded.

Both snapshots are bridged into the classifier via
`classify::inputs_from_snapshot`, then run through `classify::classify` (F-201)
and `classify::health_metrics` (F-202). No file under `E:\Books - Audio` was
created, modified, renamed, or deleted (D-09; this phase's absolute constraint).

## Reading the deltas (reported, not judged)

- **book-like folders 582 -> 582** (live) lands exactly on the FD-18 baseline;
  the CSV re-import reads 580. The one-to-two-folder wobble is real library
  churn between March and July (a couple of books added), not a classifier
  change: the CSV and live snapshots run the identical engine and differ only by
  110 entries (14,689 -> 14,799).
- **loose-root parses 237/238** reproduce the FD-18 baseline EXACTLY on both the
  CSV and the live snapshot: 237 of 238 loose root audio files parse cleanly,
  the one holdout being the deliberate non-clean outlier the F-301 pattern set
  routes to manual-review by design (AC-301.3). This is the single strongest
  cross-validation in this report: the rescued March snapshot and the fresh July
  scan agree to the file on the parser's headline number.
- **bracket / bitrate / size marker presence rose** (203 -> 222, 170 -> 212,
  214 -> 215). The bitrate jump is the largest: the newer Hugo/Nebula collection
  folders carry `[64k ...]`-style bracket tags that bundle a bitrate token, a
  duration, and a size together, so a folder gained by the library since March
  typically increments all three presence counts at once. These are presence
  counts over folder names; the SHIPPING product folds the whole
  `[64k 16;59;40 471MB]` bracket into its single bracket-tag strip pass, so the
  tool's own anchored bitrate/size passes (which target only BARE trailing
  markers) see far fewer, by design. The presence counts here exist purely to be
  like-for-like with the discovery baselines.
- **rank prefixes fell (143 -> 106), year prefixes rose (116 -> 136).** Both are
  folder-name-shape counts and both moved with the library's reorganization
  since March (more `YYYY - ...` award-year folders, fewer `N - ...` ranked-list
  folders). Reported, not judged.
- **empty folders 23 (CSV) -> 21 (live):** two fewer empty folders in July.

The CSV import surfaced **0 malformed rows** over all 14,689 data rows (G-07
satisfied: the rescued CSV imports cleanly and feeds the compare).

## Parser-coverage freeze decision (G-05)

The P4 parser-coverage metric over the P1 fixture library is **20/21 = 95.2%**
(the single non-parsing name is the deliberate `FREE SAMPLE_ The Martian by Andy
Weir.m4b` outlier, routed to manual-review by design, AC-301.3). 95.2% is above
the ~90% AC-301.4 threshold, so **the pattern set is NOT frozen**; no remainder
is force-routed to manual-review. The fresh-scan loose-root reproduction of
237/238 corroborates that the pattern set holds on real data. Recorded per G-05.
